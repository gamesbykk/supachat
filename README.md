I have developed a Math tutor using Qwen2.5-7B LLM. This Math Tutor can provide step by step working out for any given Math problem. To develop this I have followed below steps 
- Downloaded Qwen2.5-7B LLM on huggingface and finetuned it to be better at math
- Ran an inference script on a cloud server
- Coded a streamlit UI for the math chatbot 
This chatbot gives step by step working out of any matematical problem given to it
